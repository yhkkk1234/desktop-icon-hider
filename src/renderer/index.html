主题设置

92%
选择界面主题风格，调整背景透明度。"跟随系统"将自动匹配操作系统的深色/浅色模式。

图标大小

40px
调整图标显示大小，也可使用 Ctrl + 鼠标滚轮快速调整。

图标排序

选择桌面图标的排序方式，支持按名称、类型、修改时间和大小排序。

边缘自动隐藏

启用边缘自动隐藏
状态: 未启用
启用后，窗口将吸附到指定边缘，鼠标移开时自动隐藏，鼠标移到边缘时自动显示。

开机启动

开机自动启动
启用后，系统开机时将自动运行此程序，桌面图标管理将自动生效。

快捷键

Ctrl + F搜索文件
Ctrl + Alt + D显示/隐藏窗口
Ctrl + Alt + R刷新文件列表
F2重命名
Del移至回收站
Shift + Del永久删除
F5刷新
全局快捷键在任何应用下都可用，其他快捷键仅在窗口激活时有效。
