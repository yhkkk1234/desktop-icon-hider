分组显示

文件夹模式将分组显示为可打开的分组图标，拖入自动按类型命名；标签模式保持顶部标签筛选。

图标保护

锁定图标位置（禁止拖拽）

GPU 加速
开启后窗口渲染使用 GPU 合成（可能消除显示时闪白），但部分机器上透明窗口 GPU 合成可能不稳定（崩溃/黑屏）；切换后需重启应用生效。
