主题设置

92%
选择界面主题风格，调整背景透明度。"跟随系统"将自动匹配操作系统的深色/浅色模式。

图标大小

40px
调整图标显示大小，也可使用 Ctrl + 鼠标滚轮快速调整。

图标排序

选择桌面图标的排序方式，支持按名称、类型、修改时间和大小排序。

分组显示

文件夹模式将分组显示为可打开的分组图标，拖入自动按类型命名；标签模式保持顶部标签筛选。

图标保护

锁定图标位置（禁止拖拽）
开启后图标无法被拖拽移动或拖入分组，防止误操作。

边缘自动隐藏

启用边缘自动隐藏
状态: 未启用
启用后，窗口将吸附到指定边缘，鼠标移开时自动隐藏，鼠标移到边缘时自动显示，全程不干扰其他窗口工作。

文件夹预览

悬停文件夹显示内容预览
鼠标悬停文件夹时弹出内容预览。预览面板支持滚动，鼠标移入面板不会消失。

背景图片

启用自定义背景图片
24px
45%
选择一张图片作为窗口背景，模糊和暗化处理可保证图标清晰可读，营造柔和氛围。

小组件

显示小组件（时钟 / 日历）
图标自动绕开组件
开启后，桌面图标会自动重新排列并绕开小组件覆盖的区域，不会被遮挡。
在分组栏点击组件按钮添加时钟或日历组件，拖动可自由摆放位置。

自动整理规则

按文件名关键词或扩展名自动将图标归类到分组（自动创建分组）。

开机启动

开机自动启动
秒
延迟启动可避免开机时窗口抢占焦点；延迟期间原生桌面图标保持可见。

Everything 搜索

启用 Everything 搜索栏
状态: 未检测到 Everything
检测到 Everything 以管理员身份运行，搜索时会弹出 UAC 确认。请关闭：Everything → 工具 → 选项 → 常规 → 取消勾选"以管理员身份运行 Everything"，然后重启 Everything。
启用后标题栏下方显示搜索栏，回车调用 Everything 原生搜索窗口，全盘实时搜索。需要已安装 Everything。

布局管理

将分组和排序等布局配置导出为 JSON 文件，可随时导入恢复。
